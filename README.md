# MooT Optimization — 1.3.3

Веб-ассистент и Windows-агент для диагностики компьютера, управления приложениями и выполнения согласованных действий.

## Состав

- `windows-agent/` — C# / .NET 10 Windows Forms: подключение по коду, телеметрия, очередь команд, локальные подтверждения, проверка обновлений.
- `php-deploy/httpdocs/` — сайт и веб-интерфейс.
- `php-deploy/moot-private/` — PHP-сервер для shared hosting: Google OAuth, сопряжение, история, очередь действий, счётчик открытий.
- `web/` и корневые Python-модули — исходная Python-версия сервера; актуальное размещение использует PHP.
- `installer-1.3.3.iss` — сценарий установщика Inno Setup.

## Настройка PHP

1. Требуется PHP 8.4+ с PDO SQLite, cURL, OpenSSL и mbstring.
2. Разместите содержимое `php-deploy/httpdocs` в публичной папке сайта, а `moot-private` — рядом с ней, вне публичного доступа.
3. Скопируйте `config.example.php` в `config.php`. Укажите собственный домен, настройки провайдера ИИ, Google OAuth и непустой промокод. Рабочие ключи в репозиторий не добавляйте.
4. Google redirect URI: `https://ВАШ-ДОМЕН/auth/google/callback`.
5. Дайте PHP право записи в приватную папку для SQLite. Используйте HTTPS.
6. Собранный установщик разместите в `moot-private/downloads/MooT-Setup.exe`. Обновите `agent-release.json` реальными версией, размером и SHA-256 своего файла.

## Сборка Windows-агента

На Windows с .NET 10 SDK:

```powershell
dotnet publish windows-agent/MooT.Agent.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o agent-1.3.3
```

Затем соберите `installer-1.3.3.iss` в Inno Setup. Для собственного сервера задайте `MootServer` при компиляции. Пример:

```powershell
ISCC.exe /DMootServer=https://example.com installer-1.3.3.iss
```

## Возможности и ограничения

- Диагностика и текущие показатели, очистка памяти, настройки производительности с откатом.
- Запуск CS2 через Steam, запуск приложений по записи меню «Пуск», установка Minecraft Launcher из Microsoft Store.
- Полный режим после промокода: дополнительные операции и согласованные системные команды.
- Выбор личных файлов для корзины; поиск одинаковых по SHA-256 копий с подтверждением и сохранением одного экземпляра.
- При запуске агент проверяет обновления; скачанный установщик проверяется по размеру и SHA-256, установка предлагается отдельно.

Поддержка каждой операции зависит от Windows, установленного ПО и оборудования. Разгон CPU не реализован, увеличение FPS не гарантируется. Лицензия Minecraft и сторонние API оплачиваются отдельно, если это требуется их поставщиками. Установщик не подписан цифровой подписью.

## Приватность и проверка

Этот репозиторий содержит исходники, а не рабочую серверную конфигурацию. Ключи API/OAuth, пользовательские базы, токены сопряжения, логи и готовые установщики исключены. Шаблоны конфигурации содержат пустые значения секретов.

Проверки и ограничения выпуска описаны в `UPDATE-1.3.3.txt`. Полный интерактивный цикл обновления Windows и реальные установки/удаления на пользовательском ПК не проверялись автоматически.
