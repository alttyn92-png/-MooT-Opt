MooT 1.3.3

Добавлено:
- Проверка опубликованной версии при запуске. Скачивание по согласию, проверка размера и SHA-256, затем предложение открыть установщик. Старая установка сохраняется до запуска установки. Настройки и привязка находятся отдельно от программы.
- Запуск CS2 через установленный Steam с локальным подтверждением и проверкой появления процесса.
- Запуск приложений по точной записи меню Пуск. Minecraft Launcher: отдельная установка из Microsoft Store; лицензия игры и вход не автоматизируются.
- Полный режим: выбор нескольких личных файлов для корзины и проверка дубликатов по SHA-256 с выбором копий. Одна копия сохраняется; повторная проверка перед переносом.
- Ошибки отправки чата остаются видимыми после обновления истории.
- Общий счётчик открытий с начальным значением 161; реальные следующие переходы хранятся на сервере. Иконки карточек и PNG favicon.

Проверено локально:
- .NET Release build/publish, PHP lint, JavaScript syntax, Inno Setup compilation.
- 13 проверок C#: результат очистки памяти, ошибки PowerShell, сравнение версий, одинаковое содержимое/разные файлы, истечение команды, изменение копии.
- HTTP tests: очередь, изоляция аккаунтов, прогресс/подтверждение, идемпотентный результат, отмена, отзыв доступа, новые типы действий, отказ неавторизованному скачиванию обновления.
- Счётчик: конкурентные события, повторы, запрещённый Origin и переход карточки.

Ограничения:
- Первую установку 1.3.3 надо выполнить обычным установщиком: старые версии не содержат проверку обновлений.
- Полная установка поверх работающей программы и UAC автоматически в этой проверке не выполнялись. Самоподписания/цифровой подписи нет.
- Выполнение команд тестировалось с тестовым агентом; настоящие игры, установки и удаления личных файлов не запускались.
- Дубликаты: первый уровень личной папки, до 501 файла, до 256 МБ каждый и 2 ГБ чтения. Недоступные файлы пропускаются.
- Разгон CPU не реализован; не заявляется поддержка любых действий или гарантированный прирост FPS.
