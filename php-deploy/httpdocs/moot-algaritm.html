04 — Вопросы и ответы

Перед
первым запуском.

MOOT бесплатный?

Скачивание приложения бесплатное. Сторонние API могут оплачиваться отдельно по тарифам их провайдеров.

Какие модели можно подключить?

Основное подключение MOOT — Alem Plus / Qwen 3.8. У отдельного помощника можно настроить собственный API и модель. Анализ изображений требует визуальной модели.

Где вводить API-ключ?

В настройках установленного приложения. Этот сайт не собирает ваши API-ключи.

Почему Windows предупреждает об издателе?

Установщик пока не подписан цифровой подписью. Проверить целостность скачанного файла можно по SHA-256 в блоке скачивания.
