MooT Optimization Boonderking — 1.2.0

НАЧАТЬ
Локально на Windows: установите Python 3.12+, откройте start-local.cmd.
Скрипт создаст .venv, установит зависимости и запросит ключ API скрытым вводом.
Откройте http://127.0.0.1:8765/. Скачайте приложение через сайт.
Локальный вход предназначен для разработки; он недоступен в production.
Для публичного сайта используйте DEPLOY.txt и deploy.sh.
Нативному приложению Python и отдельная установка .NET не нужны.

ЧТО РЕАЛИЗОВАНО
Сохраняемый чат, история действий, Google OAuth, семизначное сопряжение.
Постоянное соединение для команд и изменений состояния; раздельная телеметрия.
CPU/ОЗУ: около 4–5 секунд; процессы: 30 секунд; оборудование: 5 минут.
Диагностика: CPU, GPU/драйвер, RAM, диски, Windows, плата, BIOS, программы,
процессы, автозагрузка, активные службы и сетевые адаптеры.
ИИ выбирает из поддерживаемых операций по запросу и данным ПК.
ОЗУ: освобождение рабочих наборов фоновых браузеров/мессенджеров, без закрытия.
Это не гарантирует падение общего объёма занятой RAM или увеличение FPS.
Очистка файлов старше 7 дней в пользовательской и системной Temp — безвозвратно,
после локального подтверждения с показом объёма. Занятые файлы пропускаются.
Поиск ограничен 100000 записей и 30 секундами; 5–10 ГБ не гарантируются.
Очистка корзины — с подтверждением на компьютере.
Схема питания, приоритет CS2/CSGO, обоснованные фоновые изменения и откат.
Компактное приложение, трей, пауза, автозагрузка, перезапуск через UAC.

ГРАНИЦЫ ВЕРСИИ
Общие задачи: модель может подготовить PowerShell-сценарий. Приложение показывает
сценарий и требует отдельного согласия. Это не песочница; универсального отката нет.
Добавлены поиск личного файла по имени и перенос в корзину, закрытие оконных
приложений, запуск штатного удаления и установка через winget. Лицензии и вход
в магазин могут требовать действий пользователя; условия не принимаются автоматически.
Разгон: ограниченный пробный NVIDIA GPU-профиль только при поддержке драйвера,
после Google-входа, UAC и подтверждения. Поддержка есть не у всех видеокарт.
CPU-разгон, изменение напряжения, SMART, температура всего ПК и замер FPS
не реализованы. Массовое отключение служб и оптимизация любой игры не заявляются.
Перечни диагностики ограничены размером отчёта. Отсутствующие данные помечаются.

ПРАВА АДМИНИСТРАТОРА
↑ возле часов Windows → правая кнопка по MooT → «Перезапустить администратором»
→ «Да» в системном запросе. Подключение восстанавливается автоматически.
Права администратора не заменяют подтверждения существенных действий.

ЛИМИТЫ И ЗАЩИТА
См. SECURITY.txt. Сервер рассчитан на один процесс и одну копию приложения.
Не увеличивайте workers/replicas без общей базы лимитов и очереди заданий.
Установщик пока не подписан коммерческим сертификатом издателя.

ПРОМОКОД
В левом меню введите MOOT. Полный режим активируется бессрочно в базе аккаунта.
После повторного входа в тот же Google-аккаунт активация сохраняется.
Локальный тестовый аккаунт привязан к cookie браузера; удаление cookie создаёт новый аккаунт.
Без промокода доступны диагностика, очистка и оптимизация. Работа с личными файлами,
установка, удаление, открытие приложений и общие сценарии требуют полного режима.
Бессрочная активация не отменяет локальное согласие на часовую сессию команд.
Первый сценарий требует согласия на автоматическое выполнение в приложении.
Далее сценарии этой сессии исполняются с правами агента без повторного вопроса.
Отозвать локальное согласие: трей MooT → Отключить автоматические команды.
После перезапуска приложения согласие запрашивается заново. Это не песочница.
Промокод на сервере меняется через MOOT_PROMO_CODE; не является аутентификацией.
