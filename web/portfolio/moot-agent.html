01 — Возможности

Меньше ручных действий.
Больше смысла в поручении.

⌘БРАУЗЕР

От слов к действиям

Открывает вкладки, находит информацию, нажимает кнопки, заполняет формы и вводит текст. Агент анализирует страницу и выполняет задачу последовательно.

≋ГОЛОС

Разговор без лишних кликов

Определяет окончание фразы, распознаёт речь и озвучивает ответ. Голосовые и текстовые сообщения сохраняются в общей истории.

◇ПЕРЕПИСКИ

Работа с чатами

Читает сообщения, готовит ответы и отправляет их с проверкой выбранной переписки. Предусмотрены инструменты для WhatsApp Web, Telegram Web и Discord Web.

02 — Постоянный мониторинг

Несколько чатов.
Ваши инструкции.

MOOT отслеживает новые сообщения и отвечает по заданным вами правилам. Наблюдения сохраняются, а новые поручения можно давать прямо во время мониторинга.

  1. 01

    Задайте правила

    Выберите чаты и объясните, как отвечать.

  2. 02

    Продолжайте работу

    Давайте агенту дополнительные задачи на разных сайтах.

  3. 03

    Сообщения ждут в очереди

    Входящие во время другой задачи обрабатываются после её завершения.

Для непрерывного мониторинга нужны работающий компьютер, открытый браузер и вкладки наблюдаемых чатов. Сон компьютера или закрытие браузера прерывают наблюдение.

03 — Установка из исходников

Начните
со своего браузера.

Инструкция из README проекта.
Настройка выполняется локально.

  1. 01

    Откройте репозиторий

    Скачайте исходники через Code → Download ZIP и распакуйте архив.

  2. 02

    Соберите проект

    Установите Node.js 20.19+. В папке проекта выполните:

    npm install
npm run build
  3. 03

    Добавьте в Chrome

    В chrome://extensions включите режим разработчика. Нажмите «Загрузить распакованное расширение» и выберите dist.

  4. 04

    Подключите API

    Откройте панель MOOT и задайте свой OpenAI API-ключ и модели. Для голоса разрешите доступ к микрофону.

04 — Вопросы

Что нужно
для работы?

Нужны ли интернет и API-ключ?

Да. Расширение использует OpenAI API и требует интернет-соединения. Ключ вводится в настройках MOOT, а использование API оплачивается по тарифам провайдера.

Где хранятся история и настройки?

Локально в профиле браузера. Для работы ИИ запросы модели, записи произнесённых фраз и текст для озвучивания отправляются в OpenAI. Сайт портфолио не собирает API-ключи.

Можно ли давать задачи во время мониторинга?

Да, текстом или голосом. Пока агент выполняет другую задачу, новые сообщения ждут обработки в очереди. Состояние наблюдений доступно в боковой панели.

Мониторинг работает при закрытом браузере?

Нет. Браузер и вкладки выбранных чатов должны оставаться открытыми, а компьютер — работать. Отслеживание зависит от доступности сайтов, сети и API.
